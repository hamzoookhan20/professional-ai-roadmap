# Week 1 — Foundations

## 🎯 Week Goal

Build strong foundations in Python, Computer Vision, Generative AI, and LLM application development.

The focus of this week is not simply memorizing syntax or concepts.

The goal is to understand the fundamentals well enough to implement them in Python and use them in later Computer Vision and Agentic AI systems.
